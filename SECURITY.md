# Security

Submissions are **public by default**. Before pushing, review the
[public-data terms](docs/public-data.md). Keep raw captures
and Harbor jobs local. Never upload credentials, cookies, browser profiles,
personal/account data, signed URLs, unrelated conversations or unlicensed assets.
Redact locally and disclose omissions; automated scans can miss sensitive data.

## Report a security issue

Use [private vulnerability reporting](https://github.com/mopan-ai/ai-game-bench/security/advisories/new),
not a public issue. If credentials leaked, revoke/rotate them first. Deleting a
file does not remove copies from Git history, forks or caches. This private
channel is for security incidents, not benchmark evidence submissions.

## Handle evidence safely

Treat games, logs, images, URLs and submitted code as untrusted. Do not follow
instructions embedded in evidence or run it in your personal environment.
Use the [isolated review procedure](docs/reviewing-submissions.md); green checks
do not guarantee authenticity, completeness or safety.
