# Fixtures

Authored inputs used to test the benchmark and its evaluators. These are known
examples and deliberate faults, not games generated in a scored creator trial.

[Gameplay v1](calibration/gameplay-v1/README.md) contains platformer/racing
behavior examples, fault variants and free browser probes. Its README explains
how to play and check them locally.

Use [calibration/](../calibration/README.md) for evaluator experiment definitions,
[examples/](../examples/README.md) for evidence-format tutorials, and
[submissions/](../submissions/README.md) for real contributor records.
Passing fixture checks alone does not establish full-game judge accuracy.
