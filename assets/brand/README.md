# AI Game Bench brand assets

Owner-supplied teal/navy identity, adopted 2026-10-25 and refreshed from the
owner's SVG exports on 2026-10-29.

- `readme-logo.svg`: horizontal logo on white, readable in both GitHub themes.
- `logo-transparent.svg`: horizontal logo with transparent surroundings.
- `logo-square.svg`: square symbol with transparent surroundings and inner cutout.
- Matching PNG exports remain available for tools that require raster images.

The sources are `AI GAME BENCH LOGO.svg` (horizontal) and `LOGO.svg` (symbol).
Both contain embedded PNG artwork, not vector paths. The exports preserve that
artwork, trim transparent outer spacing, remove embedded metadata and fit the
symbol proportionally onto a transparent square. Only the README presentation
adds a white background; website icons do not. The landing repository shares
these exports and supplies transparent SVG/ICO favicons and a PNG touch icon.

These marks identify AI Game Bench; no third-party endorsement or trademark
clearance is claimed. Other platform marks have separate
[attribution](../../platforms/LOGOS.md).
